# Micromouse Slalom Simulator

Cloudflare Workers + Static Assets 用の静的Webシミュレータです。

## 内容

- `motion_speed_profiles` の 200 / 300 / 400 / 500 mm/s プロファイル
- `turn_sim_pygame.py` を元にした 1 ms 刻みのターン計算
- コサイン形状の通常曲線と左→右専用のバイアス付き曲線
- 実測横摩擦による滑走と進行方向のずれ
- 左 / 右 / 左→右 / 右→左
- 左→右・右→左の2個目入口追加補正
- 682 g / トレッド81.9 mm / タイヤ幅6 mm
- 横加速度、横G、横力、必要摩擦係数の表示

## 横滑りモデル

黒つや消し塗装木床で、682 gの実機を真横に押したときの実測値を使います。滑り出し約160 gfから μs=0.235、滑走維持約140 gfから μk=0.205。カスタム設定では 0 ≤ μk ≤ μs ≤ 5 の範囲で調整できます。

指令横加速度 `v × |ω|` が `μs × g` を超えると滑り始めます。前進速度と車体の旋回は左右輪の指令に従うと仮定し、車体の横方向速度を独立に積分します。滑走中の摩擦は横方向速度を減らす向きに最大 `μk × g` を作用させます。横速度がゼロに戻り、必要横加速度が静止摩擦限界内なら再びグリップします。

赤の破線は推定軌道、太線は滑走区間、白丸は最初の滑り開始位置です。滑走区間長は推定軌道上の距離の合計です。横ずれは同時刻の指令位置からの差を指令進行方向に直交する軸へ投影した値です。スリップ角は車体の向きと速度ベクトルの角度差です。ヨーは指令どおりなので姿勢誤差は0°です。左右輪別の荷重、縦摩擦、壁との衝突は計算対象外です。
