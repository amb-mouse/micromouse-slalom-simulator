# Micromouse Slalom Simulator

Cloudflare Workers + Static Assets 用の静的Webシミュレータです。

## 内容

- `motion_speed_profiles` の 200 / 300 / 400 / 500 mm/s プロファイル
- `turn_sim_pygame.py` を元にした 1 ms 刻みのターン計算
- 角加速 → 等角速度 → 角減速
- スリップ角係数による進行方向補正
- 左 / 右 / 左→右 / 右→左
- 左→右・右→左の2個目入口追加補正
- 682 g / トレッド81 mm / タイヤ幅6 mm
- 横加速度、横G、横力、必要摩擦係数の表示

## 摩擦制限モデル

黒つや消し塗装木床を想定し、基準 μ=0.70 と低グリップの比較値 0.55 / 0.50 / 0.45 / 0.40、カスタム μ を選べます。プリセットは仮定値です。

指令軌道の各ステップで必要横加速度を `v × |ω|` とし、これが `μg` を超える区間では旋回方向を保ったまま実角速度の大きさを `μg/v` に制限します。速度と各区間の時間は指令値を使い、曲がりきれずに生じた姿勢ずれは後続区間に引き継ぎます。タイヤの横滑り角、縦方向の摩擦限界、壁との接触、実機のフィードバックによる復帰はモデルの対象外です。

破線は推定実軌道、太線は摩擦限界を超えた区間です。滑走距離・時間はその区間の合計で、位置ずれと姿勢ずれは同時刻の指令軌道を基準に計算します。
